# FLX Hub

Launcher Windows des jeux de Flanix (EN VISIO, Oriflamme, Le Dernier Règne, plus tes applis déjà installées).

Les builds se téléchargent depuis les [releases](https://github.com/Flanix7/flx-hub/releases) de ce dépôt.
EN VISIO reste publié sur [Flanix7/en-visio](https://github.com/Flanix7/en-visio/releases).
